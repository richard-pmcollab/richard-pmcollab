## About me

I run programs end to end: planning, risk, stakeholders, delivery. Lately I've been building AI agents in n8n that take over the repetitive parts of the job, like status reports, meeting follow-ups and risk logs, so more of my time goes to decisions and people.

This GitHub is where I publish that work: delivery templates, program case studies, and agentic workflows that any PM can import and use.

**[AI Proposes. The PM Decides.](https://github.com/richard-pmcollab/ai-proposes-pm-decides)** Seven open-source AI agents for project managers, built in n8n. They do the weekly grunt work and send me **one clear proposal**; nothing is written to any system until I approve it, and every decision is logged.

| Agent | What it does |
|---|---|
| 🧭 **PM Agent Team** | An orchestrator briefs Status, Schedule, RAID and Comms specialists, then reviews their work into one weekly proposal |
| 📊 **Weekly Status** | Scores project health with fixed rules and drafts the status report |
| 📝 **Meeting → Actions** | Turns a transcript into decisions and actions with owners, due dates and supporting quotes |
| 🗣️ **Stakeholder Translator** | Writes executive, team and client versions of one update, with a leak check on the client version |
| 📥 **Intake Triage** | Prioritises requests by rules, spots duplicates, routes them and drafts the reply |
| 🔁 **Retro Synthesizer** | Turns anonymous team feedback into themes and up to 3 measurable actions |
| ⏰ **Daily Slip Alert** | Emails me only when a milestone moves, with the cause, knock-on risk and options |

**Status:** all 7 live-tested end to end · one-command installer, or say *"install the PM agents"* in Claude Code · [install guide](https://github.com/richard-pmcollab/ai-proposes-pm-decides/blob/main/INSTALL.md) · [run it on your own project](https://github.com/richard-pmcollab/ai-proposes-pm-decides/blob/main/inputs/README.md)

## How I work

- **Structure first.** Every program gets a charter, a RAID log and a clear RACI before work starts.
- **Automate the routine, keep humans on decisions.** My agents draft and flag. A person approves anything that goes out.
- **Honest reporting.** Red means red. Early bad news costs less than late bad news.
